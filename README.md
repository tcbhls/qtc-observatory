# QTC Observatory v1.4 — 跨 AI Agent 零干扰实时任务监测与因果对照中心

**QTC Observatory** 是一款遵循 **100% 物理级零干扰原则（Zero-Interference Principle）** 的跨平台 AI Agent 实时遥测监测与因果计量分析工具（支持作为 **Google Antigravity 原生 MCP App 插件**运行，亦可作为 **全天候无头守护进程 (`daemon`)、本地 SSE 实时 Web 大屏与 CLI** 运行）。

v1.4 重构了**五维贝叶斯证据累积型任务完成质量（$Q_{\text{task}}$）评估标准**（结合 *AgentSWE* 后置确定性验证、*SPUR* 隐式行为满意度与 *ACM SIGIR* 沉默弃用区分理论），将中性待验起评基准下调至 **`62.0` 分**，彻底拉开「无反馈沉默结案（`60~66` 分）」与「客观核验闭环 + 下游生产采纳（`88~98` 分）」的区分度，并在前端逐条透明展示加减分证据明细。

## 核心数学逻辑与特性（v1.4 升级）

### 1. 告别无基线瞎比：严格的「基线 $B \to$ 实验组 $A$」受控因果对照
任何“多花成本”或“省时间”的结论必须有可比的对照基准，系统彻底剔除孤立微探针与咨询会话的虚假对比，仅在以下**受控可比配对**上计算 $(\Delta Q_{\text{task}}, s_T\%, \Delta \dot{C}\%, \Delta c\%)$，同时支持在面板自由指定任意两个会话/阶段比对：
- **① 同任务中途注入加速/优化方案前后自对照**：自动切分同一长任务在注入优化方案前（基线段 $B$）与注入方案后（实验段 $A$）的真实表现，并自动归集关联咨询顾问会话的额外规划开销。
- **② 同一工程目录跨会话迭代对照**：自动按目标工程路径 `project_key` 串联同体量前后迭代会话。
- **③ 长会话前期清爽基线 vs 后期上下文膨胀对照**：审计不重开窗口连续堆叠轮次导致的小时额度耗用率漂移。

### 2. 功率-速度微分守恒定律（解释为什么“时间没省多少，耗用率剧增”）
定义**小时额度耗用率（功率）** $\dot{C} = \frac{C}{T}\ (\text{U/h})$，相对对照基线 $B$ 的真实省时率为 $s_T = \frac{t_B - t_A}{t_B}$，耗用率增幅为 $r_{\dot{C}} = \frac{\dot{C}_A - \dot{C}_B}{\dot{C}_B}$，则单位产出总成本比精确服从：

$$\frac{c_A}{c_B} = (1 + r_{\dot{C}})(1 - s_T)$$

- **等总成本零溢价边界**：$r_{\dot{C},\text{neutral}}(s_T) = \frac{s_T}{1 - s_T}$。一旦 $r_{\dot{C}} \gg \frac{s_T}{1 - s_T}$ 且 $\Delta Q_{\text{task}} \approx 0$，即构成精确数学意义上的“捡芝麻丢西瓜”。

### 3. 五维证据累积型「任务完成质量 $Q_{\text{task}}$」准则（v1.4 核心升级）
摒弃虚高的 `90` 分默认起评，统一从 **`62.0` 分中性待验基准**起算，严格剥离过程试错与最终交付质量：
1. **实质交付深度（`0 ~ +8.0` 分）**：区分纯口头问答（`+0`）、终端实操核查（`+1.5`）、单文件落盘（`+3.5`）、多文件交付（`+6.0`）与深度工程交付（`+8.0`）。
2. **独立客观核验闭环（`-12.0 ~ +13.0` 分）**：改后构建/单元测试全绿（`+5.5`）、成品图片/PDF 视觉自检（`+3.5`）、计划清单 100% 完结（`+2.5`）、子代理交叉核验（`+1.5`）；改后零验证空心交付（`-4.0`）、终局命令报错未修（`-8.0`）、异常半途中断（`-6.0`）。
3. **真实采纳与下游转化（`-5.0 ~ +14.0` 分）**：`git commit/push` 或安装包/服务部署落库（`+6.0`）、终局显式认可或总结沉淀经验（`+5.0`）、多轮顺畅下游推进（`+4.0`）、客户端加星置顶（`+3.5`）、事后回访查阅复用（`+2.0`）；单轮沉默离开记 `±0`（停留在待定区），客户端归档弃用扣 `-5.0`。
4. **意图对齐与返工摩擦（`-38.0 ~ +4.0` 分）**：多轮一次对齐零返工（`+4.0`）；中途偏差/Bug 经闭环修复仅留轻微打磨折损（`-1.5 ~ -7.5`）；终局严重偏差未闭环（`-18.0+`）；终局质量倒退叫停（`-34.0+`）。
5. **人工校准最高覆盖权（`Q_human`）**：研究者手填真实评分拥有 100% 最高覆盖权，保存即刻触发全局回归重训。

### 4. 秒级全链路实时流与 100% 观察者零干扰
- **内核级 `fs.watch` 秒级捕获 + SSE (`/api/events`) 无感热推**：新对话步进落盘 ~1.2 秒内自动入库、在线重解 OLS 与 IRLS 方程组并热推刷新全部 6 张图表。
- **零提示词注入、零执行钩子拦截、分析工具 `visibility: ["app"]` 100% 对大模型隐形**。

## 快速使用

```bash
# 安装并构建单文件面板
npm install && npm run build

# 启动全天候无头 fs.watch 实时守护进程 (提供 http://127.0.0.1:18765 实时大屏)
npm run daemon

# (可选) 注册 Windows 零弹窗开机静默自启守护
npm run autostart

# 终端输出全机最新样本、耗用功率方程与受控因果对照榜
npm run report
```
